# GRAPHS : 


So as we know a graph is what when nodes are connected to each other using edges 

that whole system is known as graph 

there are two types of graphs 

1. Directed graphs : In which For example Node A is connected to Node B , but the relationship is just one way B isn't connected to Node A that 
is Directed Graph. 

2. Undirected Graphs : In which For example Node A is connected to Node B , and the relationship is two way B is also connected to Node A that is Undirected Graph.
