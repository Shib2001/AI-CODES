# Now a gpt transformer model is very much basically same as the google translate 

in google translate :


input sequence > "TRANSFORMER" > Output sequence


but in gpt : 

input tokens > "TRANSFORMER" > predict the next token 

example : 

Hey there > "TRANSFORMER" > I 

then the loop will run again 

Hey there I > "TRANSFORMER" > am

then the loop will run again 

Hey there I am > "TRANSFORMER" > good

then again 

Hey there I am good > "TRANSFORMER" > <END> 


So you gave input token Hey there and on the basis of the prediction of what the next token could be we got Iam good
